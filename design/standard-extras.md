# P2 추가 항목 조사: 지원서 없는 공고의 요구사항

P1(HWP 양식)과 비교하면, 지원서 없는 공고는 **영상 링크**(P1 7% → 44%)와 **메일 제목 규칙**을 훨씬 자주 요구한다. 양식이 없으니 그만큼 제출 방식을 본문에서 정하기 때문이다.

## 결정 (2026-10-03)

아래 제안 1~3을 그대로 정했다(`standard-form.md` 결정 9~11). 추가 항목 목록에는 자주 나오는 4개, 예·아니오 질문, P1 추가 후보, 직접 적기를 모두 넣는다.

## 제안

1. **지원 배역을 운영자가 고르게**: 기본 줄 "지원 배역"을 공고마다 `글 입력` 또는 `배역 목록에서 고르기(하나 / 여러 개)`로 정한다. 목록은 운영자가 공고 본문에서 옮겨 적는다.
2. **추가 항목 목록**(운영자가 체크해서 붙임):
   - 영상 링크(줄 표, 최대 3줄: 설명 / 링크)
   - 나이
   - SNS
   - 음역대
   - 오디션 가능 날짜(운영자가 날짜를 적고 배우가 고름)
   - 지방·순회 공연 가능(예·아니오)
   - 운전 가능(예·아니오)
   - 소속
   - 영문 이름
   - 병역
   - 직접 적기(글 / 예·아니오 / 고르기)
3. **제출 안내**(문서 밖, 새 기능): 공고마다 받는 이메일, 메일 제목 규칙(`{name}`처럼 항목으로), 마감일, 함께 낼 것(영상 파일 등)을 적어 두면, 완료 화면에서 메일 제목을 채워 보여 주고 복사 버튼과 받는 사람·제목이 채워진 메일 쓰기를 연다. 서버가 메일을 보내지는 않는다. HWP 공고에도 쓸 수 있다.
4. **사진·경력 안내 문구**는 공고별로 운영자가 바꿀 수 있게 한다(최근 6개월 사진, 정식 공연 경력만 등).
5. 범위 밖: 영상 파일 첨부(링크만), 온라인 폼 공고, 동의서.
