## 조사 범위와 기준

- 사용자가 지정한 `22289`부터 번호를 하나씩 줄이며 브라우저에서 각 게시글을 직접 열었다.
- 첫 100개 번호인 `22289~22190`에는 공개 게시글 77개, 삭제·미존재 22개, 비밀글 1개가 있었다. 공개 게시글 77개 중 직접 첨부 있음 33개(42.9%), 없음 44개(57.1%).
- 공개 게시글 100개를 확보하려고 `22158`까지 조사했다. 총 132개 번호: 공개 100개, 삭제·미존재 31개, 비밀글 1개.
- 게시일 범위는 2026-09-08~2026-09-20. 조회일은 2026-10-03(한국 시간).
- 비율의 분모는 공개 게시글 100개. 재공고·중복 모집도 게시글마다 각각 센다. 조연출·매표 아르바이트·진로강사 모집과 합격자 발표도 임의로 제외하지 않았다. 고유 작품이나 배우 모집만의 비율은 아니다.
- 직접 첨부는 OTR의 '첨부파일' 행에 표시된 파일만 센다. 본문에 삽입된 포스터 이미지는 직접 첨부에 넣지 않는다. JPG·PNG가 '첨부파일' 행에 있으면 직접 첨부로 센다.
- 형식은 페이지에 표시된 파일명의 확장자 기준이다. 전체 파일을 다운로드해 시그니처·내용·편집 가능성을 검사한 결과는 아니다. ZIP 내부는 조사하지 않았다.
- 외부 지원서 링크는 따로 기록했다. 22235는 Google Docs 화면의 `.DOC` 배지와 지원서 제목, 22220은 Drive 폴더의 `.docx` 지원서 파일명을 직접 확인했다.
- '직접 첨부 없음'은 '지정 양식 없음'과 다르다. 이미지 속 QR·URL과 모든 외부 사이트까지 전수 추적한 조사는 아니다.
- 표의 제목은 식별하기 쉽게 일부 축약했다. 파일명은 한글 Unicode NFC로 정규화했으며 의미는 변경하지 않았다.
