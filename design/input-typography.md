# 지원서 입력 글꼴 정규화

## 사용자 결정

- 결정일: 2026-09-23
- 선택: 업로드한 양식마다 대표 글꼴을 고르고, 지원자가 입력한 글자에만 적용한다.
- 이유: 제목·항목명·안내문 등 원본 양식의 디자인을 보존하면서 입력 내용의 이질감을 줄인다.

## 적용 범위

- 새 텍스트로 교체하는 칸과 기존 라벨 아래에 내용을 덧붙이는 칸 모두 입력 부분만 정규화한다.
- 원본 라벨·안내문·빈 줄·사진·표 구조·문단 배치는 변경하지 않는다.
- 문서마다 원본의 표 본문에서 가장 빈번한 한글 글꼴을 대표 글꼴로 선택한다. 같은 빈도면 먼저 등장한 것을 쓴다. 대표 글꼴을 확인할 수 없으면 원본 칸의 글꼴을 유지한다.
- 입력 글자는 검은색·보통 굵기·기울임 없음으로 맞춘다. 크기는 각 표에서 가장 흔한 본문 크기를 기본으로 쓰되, 그 값을 알 수 없으면 원본 칸의 크기를 유지한다.
- 새 외부 글꼴이나 API 입력 항목은 추가하지 않는다. 기존 `HwpDocument` 생성 흐름과 `hwplib` 서식 정보 안에서 처리한다.

## 검증

- 서로 다른 원본 글꼴을 가진 입력 칸의 결과가 한 문서 안에서 같은 대표 글꼴을 사용한다.
- 덧붙이는 칸의 기존 라벨 서식은 그대로이고 입력값에만 대표 글꼴이 적용된다.
- 생성 HWP를 다시 열 수 있으며, 기존 양식의 나머지 셀과 페이지 수를 유지한다.
- PDF·미리보기는 시스템 글꼴 대체가 발생할 수 있으므로 HWP 내부 서식 검증과 별도로 확인한다.
