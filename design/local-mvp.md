# 예술IN 배우 지원서 자동 완성 로컬 MVP 설계

## 상태

- 확정일: 2026-09-22
- 문서 엔진: Java `hwplib 1.1.11`
- 결정자: 사용자
- 범위: 로컬 MVP

## 확정 결정

| 주제 | 결정 | 이유 |
|---|---|---|
| 프로젝트 구성 | `backend/` Spring Boot와 `frontend/` React 분리 | 문서 처리와 화면의 개발·테스트 경계를 분리한다. |
| 필드 추출 | 표 라벨과 빈 입력 영역을 자동 추출하고 사용자가 확인 | 특정 지원서 좌표에 종속되지 않으면서 오탐을 사람이 교정할 수 있다. |
| 파일 보존 | 요청별 임시 작업공간, DB 없음 | 개인정보를 장기 보관하지 않는 로컬 MVP를 우선한다. |
| API 흐름 | 분석과 생성의 2단계 API | 자동 추출 결과를 확인한 뒤 원본을 수정한다. |

## 사용자 흐름

1. 사용자가 `.hwp` 파일을 업로드한다.
2. 서버가 표와 셀을 읽고 텍스트 필드 및 사진 슬롯 후보를 반환한다.
3. 사용자가 후보의 이름, 위치, 입력값을 확인하거나 수정한다.
4. 사용자가 사진을 슬롯에 연결한다.
5. 서버가 보관 중인 원본의 선택된 셀에 텍스트와 사진을 삽입한다.
6. 완성된 `.hwp`를 다운로드한다.
7. 작업 파일은 짧은 TTL 뒤 삭제한다.

## 공개 API

### `POST /api/documents/analyze`

- 입력: `multipart/form-data`, `document` 한 개
- 허용 형식: `.hwp`
- 출력: 문서 ID, 만료 시각, 표 구조 요약, 텍스트 필드 후보, 사진 슬롯 후보
- 문서 ID는 서버가 생성한 불투명 UUID다.

### `POST /api/documents/{documentId}/generate`

- 입력: `multipart/form-data`
  - `request`: 선택된 셀 주소와 값, 선택된 사진 슬롯과 multipart 파일 키를 담은 JSON
  - 사진 파일: 요청에서 참조한 키별 JPEG 또는 PNG
- 출력: `application/x-hwp` 첨부 파일
- 셀 주소는 `tableIndex`, `rowIndex`, `cellIndex`의 정수 조합이다.

## 필드 추출 규칙

- 각 표의 셀을 행 순서로 조사한다.
- 값이 있는 셀을 라벨 후보로 보고 같은 행의 다음 빈 셀을 입력 후보로 연결한다.
- 병합 셀의 실제 행·열 주소와 span을 응답에 포함한다.
- `사진`, `프로필`, `얼굴`, `상반신`, `전신`, `자유`가 포함된 라벨은 사진 슬롯 후보로 분류한다.
- 입력 후보가 없거나 여러 개로 모호하면 자동 확정하지 않고 경고를 포함한다.
- 사용자가 확인한 셀 주소만 생성 단계에서 수정한다.

## 안전 경계

- 업로드 파일명은 저장 경로로 사용하지 않는다.
- HWP 시그니처와 크기 제한을 검사한다.
- 사진은 JPEG/PNG 시그니처와 크기 제한을 검사한다.
- document ID를 경로로 직접 결합하지 않는다.
- 작업공간 밖의 경로는 읽거나 쓰지 않는다.
- 만료되거나 없는 문서는 동일한 타입의 오류로 반환한다.
- 생성 실패 시 원본 파일은 수정하지 않고 임시 출력만 폐기한다.

## 기술 기준

- Backend: Java 25, Spring Boot 4.1.1, Gradle wrapper, `hwplib 1.1.11`
- Frontend: React, TypeScript, Vite
- Backend 테스트: JUnit 5 및 Spring MVC 통합 테스트
- Frontend 테스트: Vitest, Testing Library
- 기본 경로에는 AI를 사용하지 않는다.

## 완료 조건

- 실제 `공부의신_오디션지원서.hwp`에서 필드와 사진 슬롯 후보를 반환한다.
- 사용자가 확인한 여러 텍스트 셀과 네 사진 슬롯을 한 번에 반영한다.
- 생성된 파일을 `hwplib`로 다시 열 수 있다.
- 오류가 한국어로 구체적으로 표시된다.
- 데스크톱과 좁은 화면에서 업로드, 검토, 생성 흐름을 완료할 수 있다.
- 키보드 포커스와 파일 입력 접근성이 유지된다.
