# 지원서 입력 초안 복원

2026-10-05 사용자가 사진을 제외한 작성 내용을 IndexedDB에 저장하고 뒤로가기·재방문 때 이어 쓰도록 요청했다. 보관 기간은 **마지막 수정 후 7일 + 직접 삭제**를 선택했다.

- 공고별 `/apply/{vid}`의 입력 초안만 같은 브라우저·사이트의 IndexedDB에 보관한다. 배우 계정이나 서버 저장은 추가하지 않는다. 운영자 테스트 입력은 저장하지 않는다.
- 텍스트·전화·선택값·경력 행과 직접 정한 완성 파일 이름을 저장한다. 사진/File/Blob, 생성 파일, 작업 ID, 수정 토큰은 저장하지 않는다.
- 저장소를 읽은 뒤 입력 화면을 열어 빈 초기값이 기존 초안을 덮어쓰지 않도록 한다. 입력 이벤트마다 쓰기 트랜잭션을 시작하고 커밋 완료 이후에 저장 완료를 표시한다.
- 양식 버전이 바뀌어도 ID·종류·라벨·경력 열 구조가 같은 항목은 복원한다. 의미가 달라진 항목과 사라진 선택지는 복원하지 않고 양식 변경 안내를 표시한다.
- 복원한 사진 항목은 비워 두며 다시 선택하도록 안내한다. 지원서 생성 후에도 초안은 유지한다. 완성 파일의 직접 편집 내용은 입력 초안에 포함하지 않는다.
- 저장된 내용 지우기에는 화면 내 확인을 제공한다. 현재 입력과 파일 이름을 초기화하고 해당 공고 초안을 삭제한다. 다른 공고에는 영향을 주지 않는다.
- 저장 실패·차단·응답 지연 시 작성은 계속 허용하고 자동 저장이 안 된다는 안내를 표시한다. 입력값·저장 오류의 원문은 로그·분석에 보내지 않는다.
- 7일 지난 초안은 복원하지 않으며 다음 저장소 접근 때 만료된 초안을 삭제한다. 브라우저가 닫혀 있을 때 시각에 맞춰 실행되는 삭제 작업은 아니다. 사이트 데이터 삭제·브라우저 저장소 회수·사생활 모드·다른 기기에서는 복원이 보장되지 않는다.
- 저장소는 `yesulin-application-drafts` / `drafts`, 키는 공고 번호다. 스키마 번호·양식 버전·마지막 수정 시각·호환성 구조와 문자열만 보관한다. 여러 탭의 같은 공고는 마지막으로 저장한 탭의 내용이 다음 방문 때 복원된다.

구현 기준: [IndexedDB 트랜잭션 완료](https://developer.mozilla.org/en-US/docs/Web/API/IDBTransaction/complete_event)는 커밋 이후에 발생한다. 저장 완료 표시를 요청 성공과 구분한다.
